# 0003: StatiCrypt with a PIN keypad for the published site

**Status:** accepted, October 2026

**Context.** GitHub Pages sites are public, and so is this repository. Typing a password with a TV remote is painful.

**Decision.** When the `SITE_PASSWORD` secret is set, `lock/publish.sh` encrypts the published pages with StatiCrypt, using `lock/template.html`. The template has an on-screen keypad you can drive with arrows, and "Remember this screen" is ticked. The salt is fixed, so being remembered survives every deploy.

**Consequences.**
- The lock hides the site, not the code.
- A short PIN could be guessed offline by someone determined. That's accepted because no secrets are in the pages: keys and the calendar address stay in each device's browser.
- `household.json` isn't encrypted, so it must hold nothing private.
- Cloudflare Access is the upgrade if the site ever shows private data.
